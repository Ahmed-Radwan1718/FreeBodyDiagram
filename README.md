# FreeBodyDiagram

A local-first free-body diagram maker.

## Current state

The first version is intentionally minimal:

- empty left sidebar
- gridded drawing workspace
- no drawing tools yet
- no framework or runtime dependencies

## Run locally

Requires Node.js.

```bash
npm run dev
```

Then open:

- `http://localhost:3000` on this computer
- `http://<your-local-IP>:3000` from another device on the same network

The development server listens on all network interfaces so the site is available over your LAN.
